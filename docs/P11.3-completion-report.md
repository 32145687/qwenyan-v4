### 1.1 Draft 持久化（storage）

- [`Draft.sq`](file:///workspace/storage/src/main/sqldelight/com/qianyan/storage/db/Draft.sq)：新增 `ChapterDraft` 表，字段与 core:model `Draft` 一一对应（draft_id / novel_id / variant_id / scope / chapter_id / chapter_plan_id / content / status / source_model / created_at / updated_at）。**未擅自加任何字段**；正文独立成表，不依赖 MemoryEntry；`insertDraft` 使用 `INSERT OR REPLACE`（幂等 save），`listDraftsByNovel` 按 `created_at, draft_id` 稳定排序。
- [`2.sqm`](file:///workspace/storage/src/main/sqldelight/com/qianyan/storage/db/2.sqm)：v2 → v3 migration，**只增 ChapterDraft**，不删除/修改既有业务表。
- [`DatabaseInitializer`](file:///workspace/storage/src/main/kotlin/com/qianyan/storage/db/DatabaseInitializer.kt)：新增 v2→v3 分支（`!tableExists(ChapterDraft)` → `Schema.migrate(2, 3)`），幂等；全新库直接 `Schema.create` 建出 v3（含 ChapterDraft）。
- [`DraftRepository`](file:///workspace/storage/src/main/kotlin/com/qianyan/storage/repository/DraftRepository.kt) / [`SqliteDraftRepository`](file:///workspace/storage/src/main/kotlin/com/qianyan/storage/repository/SqliteDraftRepository.kt)：最小 API `save / getById / listByNovel`，与既有 `SqliteMemoryRepository` 风格一致。
- [`StorageMappers`](file:///workspace/storage/src/main/kotlin/com/qianyan/storage/repository/StorageMappers.kt)：`domainDraft` / `dbDraft` 双向映射（ID / 枚举名 / epoch 毫秒时间）。

### 1.2 Writing 类型化错误

- [`WritingException`](file:///workspace/application/src/main/kotlin/com/qianyan/application/usecase/writing/WritingException.kt)：`InvalidOutput` / `Failed`（结构参照 PlanningException）。
- [`ApplicationError.InvalidWritingOutput` / `WritingFailed`](file:///workspace/application/src/main/kotlin/com/qianyan/application/error/ApplicationError.kt#L110-L117) + [`ErrorMapper`](file:///workspace/application/src/main/kotlin/com/qianyan/application/error/ErrorMapper.kt#L44-L46) 接入。
- **禁止 String.contains 判断错误类型**，一律按异常/错误具体类型映射。

### 1.3 DraftParser

- [`DraftParser`](file:///workspace/application/src/main/kotlin/com/qianyan/application/usecase/writing/DraftParser.kt)：LLM 原始输出 → **现有** `Draft`（不新建重复模型）。
  - 结构信息（draftId / novelId / variantId / scope / chapterId / planId / sourceModel / 时间）由 `DraftStructure`（来自 ChapterPlan + 上下文）提供，**不让 LLM 生产领域 ID / 时间**；
  - content 必填且为 String：空输出 / 非 JSON / 缺 content / content 类型错误 / 空白正文 → `WritingException.InvalidOutput` → 类型化 `InvalidWritingOutput`；
  - **绝不把解析失败伪装成成功 Draft**。

### 1.4 WriterAgent

- [`WriterAgent`](file:///workspace/application/src/main/kotlin/com/qianyan/application/usecase/writing/WriterAgent.kt)：复用 P10 `AgentRuntime`，只依赖 `:provider:api` 的 `LLMGateway` 抽象。
  - **不依赖 provider:impl / HTTP / API Key / SQLite**；不重写 AgentRuntime / ToolSystem；无 writing Tool（P11.3 不要求）；
  - 输入使用 `PlanningContext + ChapterPlan`（不创建第二套 WritingContext）；
  - 默认 `ModelProfile.MOCK`，测试确定性；
  - ProviderException / AgentException / ToolException 全部映射为类型化 ApplicationError。

### 1.5 WritingSnapshot

- [`WritingSnapshot`](file:///workspace/application/src/main/kotlin/com/qianyan/application/usecase/writing/WritingSnapshot.kt)：Draft ↔ Checkpoint `snapshot`（JsonObject，`type=WRITING` 标签）编解码；保存 Draft 必要字段，restore 可完整还原；**复用 P8.1/P8.2 Checkpoint，不新增数据库表**；正文不依赖 MemoryEntry。

### 1.6 WritingExecutionUseCase

- [`WritingExecutionUseCase`](file:///workspace/application/src/main/kotlin/com/qianyan/application/usecase/writing/WritingExecutionUseCase.kt)：
  - 校验 Task.type == WRITING（否则 InvalidOperation；不存在 → TaskNotFound）；
  - `PENDING → start → context assembly → writer.write → DraftParser → DraftRepository.save → saveCheckpoint(WRITING, WritingSnapshot) → complete → COMPLETED`；
  - 失败：`RUNNING → fail（保存类型化 Task error）→ 抛类型化错误 → FAILED`；**不伪造 Draft**；
  - `draftFrom(checkpoint)` 只读恢复 Draft（不重新执行）；
  - **未修改 TaskStateMachine**。

### 1.7 TaskRunner 最小扩展

- [`TaskRunner`](file:///workspace/application/src/main/kotlin/com/qianyan/application/usecase/task/TaskRunner.kt)：新增 `executeWriting(taskId, request, plan)` 专用入口，转发 `WritingExecutionUseCase`；**通用 `execute` 未改动**；IMPORT / PLANNING 原行为不变；WRITING 之外其余未支持类型继续类型化拒绝。**未改造成 Workflow Engine / Orchestrator / Agent Runtime**。

### 1.8 ApplicationContainer

- [`ApplicationContainer`](file:///workspace/application/src/main/kotlin/com/qianyan/application/di/ApplicationContainer.kt)：新增 `draftRepository: DraftRepository`（`fromDriver` → `SqliteDraftRepository(db)`）+ `writer: WriterAgent` + `writingExecution: WritingExecutionUseCase`，`taskRunner` 注入 writing。依赖方向：application → agent:runtime / agent:tool → provider:api；application → storage；WriterAgent → LLMGateway（:provider:api）。
