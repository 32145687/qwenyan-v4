## 3. TaskRunner 设计

`TaskRunner` 是一个**非常薄的执行适配器**（[TaskRunner.kt](file:///workspace/application/src/main/kotlin/com/qianyan/application/usecase/task/TaskRunner.kt)）：

- 只复用 `TaskManagerUseCases.start / saveCheckpoint / complete / fail / findById`，**不绕过状态机**（不 `task.copy(status=...)`、不直写 Repository）。
- `execute(taskId, source, title)` 按 `task.type` 分派：
  - `IMPORT` → `executeImport`（P8.3 唯一受管执行类型）；
  - `ANALYSIS / WRITING / PLANNING / KNOWLEDGE_UPDATE` → 抛 `ApplicationError.UnsupportedTaskType`（P8.3 无执行能力），拒绝发生在 `start` 之前，Task 保持 PENDING。
- 兜底：未归一异常经 `errorMapper.map` 后落 FAILED，不吞、不泄漏原始异常。

## 4. IMPORT 执行链路

```text
execute(IMPORT)
  → taskManager.start(taskId)                    // PENDING → RUNNING（状态机校验）
  → guard { txtUseCases.importTxtAsOriginal(source, title) }   // 真实执行既有 UseCase（同步）
  → taskManager.saveCheckpoint(taskId, "IMPORT", snapshot)     // 保存输入/输出上下文
  → taskManager.complete(taskId)                 // RUNNING → COMPLETED（终态，progress=1.0）
```

失败路径：

```text
execute(IMPORT, 空正文/坏字节)
  → start()                                        // PENDING → RUNNING
  → importTxtAsOriginal 抛 EmptyDocument（TxtException → ApplicationException）
  → taskManager.fail(taskId, error)                // RUNNING → FAILED（记录错误）
  → 继续抛出原类型化错误（ApplicationException）
```

`source` 处理：不修改 `TxtUseCases` API / TXT pipeline / 不新增 source abstraction；TxtSource 的 bytes 仅本次执行使用，snapshot 只存 `displayName` 元信息（不持久化 bytes，不改 core:model）。

## 6. Checkpoint snapshot（结构化 JSON）

沿用 `Checkpoint.snapshot: JsonObject?`，**不新增数据库列、不给 Task 加 input/output 字段、不新增 JSON 库**（kotlinx.serialization，与 P8.2 一致）：

```json
{
  "type": "IMPORT",
  "input": { "title": "我的小说", "source": "novel.txt" },
  "output": {
    "documentId": "...", "novelId": "...", "isDuplicate": false,
    "contentHash": "...", "encoding": "UTF8",
    "charCount": 0, "chapterCount": 2, "blockCount": 3
  }

```

字段全部取自真实 `TxtImportOutput` API，无凭空字段。`restoreCheckpoint()` 只恢复最近 Checkpoint 上下文，**不重新执行任务**（TaskExecutionTest 验证恢复后状态仍为 COMPLETED，未重跑）。

事务边界：沿用 P8.2 约定，`update()` / `saveCheckpoint()` 为独立事务；未要求新增 Repository 原子 API（无需扩大 P8.1）。
